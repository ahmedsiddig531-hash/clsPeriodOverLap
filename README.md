# C++ Date Period Library

A simple C++ `clsPeriod` class built on top of the `clsDate` class.

The class represents a period using a start date and an end date and provides functionality to check whether two date periods overlap.

## Features

- Define a period using a start date and end date
- Check whether two periods overlap
- Compare periods using `clsDate`
- Print the start and end dates of a period
